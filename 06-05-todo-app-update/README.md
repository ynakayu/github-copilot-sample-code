# ToDoアプリ

このプロジェクトは、シンプルなToDoアプリです。ユーザーがタスクを入力し、リストに追加・削除・編集することができます。

## 機能
- タスクの追加
- タスクの削除（チェックボックスを使用）
- タスクの編集（タスクをクリックして編集）

## 使い方
1. `index.html` をブラウザで開きます。
2. テキストボックスにタスクを入力し、「追加」ボタンをクリックします。
3. 入力したタスクがリストに表示されます。
4. 削除したいタスクのチェックボックスをオンにし、「削除」ボタンをクリックします。
5. 編集したいタスクをクリックすると、編集フォームと「編集」ボタンが表示されます。
6. 編集フォームに新しいタスクを入力し、「編集」ボタンをクリックするとタスクが更新されます。

## ファイル構成
- `index.html`: アプリのUI
- `todo-list.js`: タスク追加・削除・編集のロジック
- `README.md`: プロジェクトの概要と使い方
