# ToDoアプリ

このプロジェクトは、シンプルなToDoアプリです。ユーザーがタスクを入力し、リストに追加・削除することができます。

## 機能
- タスクの追加
- タスクの削除（チェックボックスを使用）

## 使い方
1. `index.html` をブラウザで開きます。
2. テキストボックスにタスクを入力し、「追加」ボタンをクリックします。
3. 入力したタスクがリストに表示されます。
4. 削除したいタスクのチェックボックスをオンにし、「削除」ボタンをクリックします。

## ファイル構成
- `index.html`: アプリのUI
- `todo-list.js`: タスク追加・削除のロジック
- `README.md`: プロジェクトの概要と使い方
