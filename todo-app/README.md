# ToDoアプリ

このプロジェクトは、シンプルなToDoアプリです。ユーザーがタスクを入力し、リストに追加・削除・編集することができます。

## 機能
- タスクの追加
- タスクの削除（チェックボックスを使用）
- タスクの編集（タスクをクリックして編集）
- **タスクの完了（チェックボックスを使用して取り消し線を適用）**

## 使い方
1. `index.html` をブラウザで開きます。
2. テキストボックスにタスクを入力し、「追加」ボタンをクリックします。
3. 入力したタスクがリストに表示されます。
4. 削除したいタスクのチェックボックスをオンにし、「削除」ボタンをクリックします。
5. 編集したいタスクをクリックすると、編集フォームと「編集」ボタンが表示されます。
6. 編集フォームに新しいタスクを入力し、「編集」ボタンをクリックするとタスクが更新されます。
7. **完了したいタスクのチェックボックスをオンにし、「完了」ボタンをクリックすると、該当タスクに取り消し線が適用されます。**

## 改善点
- チェックボックスにチェックが入っているタスクが1つ以上ある場合のみ、「削除」「完了」ボタンが表示されるようになりました。
- チェックボックスにチェックが入っているタスクが0件の場合、「削除」「完了」ボタンは非表示になります。

## ファイル構成
- `index.html`: アプリのUI
- `todo-list.js`: タスク追加・削除・編集のロジック
- `README.md`: プロジェクトの概要と使い方
